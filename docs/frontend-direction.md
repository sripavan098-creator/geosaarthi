# Mission-Control Frontend Direction

The supplied frontend prompt supersedes the earlier editorial-light treatment for the visual layer while preserving GeoSaarthi’s evidence-first product principles. The updated interface will present a dark satellite mission-control aesthetic: midnight-blue depth, electric-cyan signals, restrained amber warnings, luminous hairline borders, geospatial grid lines, and a compact technical type scale. The experience will emphasise a living orbital scanner, satellite telemetry, analysis orchestration, image evidence, confidence, and provenance rather than decorative effects alone.

The user archive provides two high-resolution, square satellite-image assets suitable for the interactive hero and analysis-viewer surfaces. `optical-terrain.png` is a colour optical aerial landscape with a city, river, agricultural parcels, coastline, and strong orbital horizon; it will support the Earth-observation hero and optical viewer. `sar-radar.png` is a monochrome SAR-style coastal image with existing coordinate, orientation, acquisition, and scale annotations; it will support the optical–SAR fusion studio. These supplied assets will be uploaded to project storage and referenced by their durable project URLs rather than copied into the application bundle.

The frontend scope remains the bounded SIH26167 demo. It will create a cinematic, responsive showcase and a functional intelligence workspace that reuses the existing validation, workflow routing, reports, metadata-only persistence, and safety boundaries. Features requiring external data feeds, a real 3D globe provider, live satellite telemetry, training workloads, or model execution beyond the current backend contracts remain clearly presented as prototype/mission-simulation UI rather than being misrepresented as live services.
