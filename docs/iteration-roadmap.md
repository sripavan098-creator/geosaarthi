# GeoSaarthi Iterative Experience Roadmap

The supplied feature universe is intentionally extensive. The active implementation sequence prioritizes features that deepen the SIH26167 demo without suggesting that GeoSaarthi has live satellite feeds, operational geospatial accuracy, or a production model estate. The interactive Earth is therefore framed as an area-of-interest simulator backed by the supplied benchmark imagery; satellite telemetry and mission feed are likewise explicitly labelled as demo simulation.

| Iteration | User-facing capability | Bounded implementation |
|---|---|---|
| 1 | Earth explorer | Clickable area-of-interest map, selectable layers, coordinate readout, visual Earth view, and a hand-off to the analysis console. |
| 2 | Time machine | Before/after and difference views, a slider, active layer switching, transparent change evidence, and explicit observed-change language. |
| 3 | Voice + query guidance | Browser-native speech recognition where supported, fallback guidance, recent prompt history, precision suggestions, and routing explanation. |
| 4 | Judge observatory | Scripted-demo benchmark cards, workflow coverage, trace completeness, and prototype latency ranges—not fabricated live model scores. |
| 5 | Mission telemetry | Simulated satellite state, pass card, capture path, and activity feed with a visible simulation label. |

Live imagery ingestion beyond the existing metadata-only flow, a real map service, a real 3D globe provider, live satellite ephemeris, model inference, and production analytics require separately connected data providers or model adapters. They will remain out of scope until the relevant service and evaluation plan are confirmed.
